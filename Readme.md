BestsellerLens

This AI is an intelligent market-validation tool for authors, publishers, and online bookstores. By analyzing a book's current market signals—such as pricing, rating, genre, and author history—it predicts whether a new or existing book has the commercial momentum to become a Top 50 Bestseller, all by simply pasting an Amazon URL.


How to Present the "Top 50 / Bottom 50" Concept:
Class 1 (Top 50) = "High-Velocity" or "Bestseller Trajectory"
Class 0 (Bottom 50) = "Standard Performance" or "Low Momentum"
